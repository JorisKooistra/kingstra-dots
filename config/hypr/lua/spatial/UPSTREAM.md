# Hyprscroll2D in Kingstra

MIT-licensed layout core and adapter from https://github.com/kirollosatef/hyprscroll2d
at f8d4eddf057769db0fef7c1191e845126abcf4cd.

Kingstra adds simultaneous pixel deltas, bounded panning, full-size first window,
a read-only overview snapshot and its own conditional bindings. Upstream's
Omarchy installer and keybindings are not included.

The custom layout is registered when supported; existing workspaces keep their
layout until the user explicitly chooses Ruimtelijk werkvlak.
